# Spec: 画面の見方を説明する図

## 概要

画面に出ているものが何を意味するのかを、1枚の SVG で示す。
プレイヤーが遊び始める前に読むもの（README）であると同時に、
`conductor/product-guidelines.md` が文章で定めている「色の意味」を
実際の見た目と突き合わせられるようにする。

## 背景

- README には「操作方法」（どこをクリックすると何が起きるか）はあるが、
  **画面の各部が何を表しているかの説明がない。** 艦の色の違い、艦を囲む円、
  艦の下のバー、ステータス欄の各行が、読み取れないまま始めることになる。
- Product Guidelines は「色は意味を持たせる。装飾のために色を増やさない」と定め、
  シアン=自軍 / 黄=警告 / 赤=危険 / 緑=良好 / オレンジ・マゼンタ=敵
  という対応を持っている。**この対応は文章の中にしか存在せず、実際の描画と
  突き合わせる手段がない。** 実装との食い違いに気づけない状態が続いている。
- `docs/screenshot1.png`（README 冒頭）は v0.3 期のもので、
  ステータス欄の構成が現在と全く違う。図で補う必要がある。

## 機能要件

### 図（`docs/screen-guide.svg`）

- **形式は SVG とする。** テキストなので `git diff` で変更が読め、
  色を `DRAW_COLOR` / `MSG_COLOR` / `:root` と同じ値で書ける。
  追加のライブラリもビルド工程も要らない。
- **艦の形は `index.html` の `preload()` の描画命令をそのまま転記する。**
  想像で描かない。Phaser の `fillRect` / `fillEllipse` / `fillCircle` は
  SVG の `<rect>` / `<ellipse>` / `<circle>` に1対1で移せる。
- 次の3区画を含む。
  1. **ステータス欄** — 各行が何を表すか。ゲージが赤に変わるしきい値。
     `Federation N (Dock M)` が自機を含むこと。
  2. **盤面の記号** — 自機・連邦艦・敵艦・基地・恒星・宇宙域の境界。
  3. **艦のまわりの表示** — シールド円（残量で色と太さが変わる）、
     シールドバー（色が艦種を示す）、自機だけのエネルギーバー、
     射程円、ドッキングの輪、ビームの色。
- **GitHub 上で `![](docs/screen-guide.svg)` として表示できること。**
  GitHub は SVG を無害化するため、外部参照・`<script>`・`<style>` を使わず、
  色はすべて属性に直接書く。フォントは総称ファミリ（`monospace`）のみ。
- `viewBox` を持ち、幅に追従すること。

### 参照

- `README.md` に「画面の見方」の節を新設し、「操作方法」の前に置く。
- `conductor/product-guidelines.md` の色の対応表から図を参照する。

### 古いスクリーンショットの削除

- **`docs/screenshot1.png` を削除する**（2026-07-29 に範囲へ追加）。
  v0.3 期のもので、ステータス欄の構成が現在と全く違い、自機の色も旧い。
  図と並べると食い違って見える。README からの参照も外す。

## 範囲外

- **新しいスクリーンショットの撮影。** `docs/screenshot1.png` は削除するが
  （下記）、代わりの画像を撮るかどうかは別の判断とする。
- **ゲーム内ヘルプ画面の実装。** `index.html` には手を加えない。
  常時表示の規約（Product Guidelines「ミニマリズムと明確性」）との
  調整が必要になり、図を作ることとは別の作業になる。
- **図の自動生成。** ゲームから SVG を吐く仕組みは作らない。
  1枚の静的な図で足りる。
- **英語版の作成。**
- **効果音・演出の説明。** 静止画で示せるものに限る。

## 完了の定義

- 図に描いた色としきい値が、`index.html` の定義と一致している。
- 実際のゲーム画面と並べたとき、説明もれの記号がなく、
  図にしかない記号もない。
- README と Product Guidelines の両方から図に到達できる。
