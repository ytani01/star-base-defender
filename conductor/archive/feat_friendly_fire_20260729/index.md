# Track: 射線上の当たり判定と誤射

ビームが射線上で最も近いオブジェクトに当たるようにする。
味方が手前にいれば誤射になる。
連邦艦と敵艦は、味方を巻き込む射線では撃たないよう行動する。

当初は「味方だけが当たり判定を持つ」形で始めたが、作業中に
「所属によらず最も近いものに当たる」形へ広げた（spec の決定事項1）。

- [Spec](./spec.md) — 何を実現するか、何をやらないか
- [Plan](./plan.md) — フェーズ分けしたタスクリスト（進捗の唯一の正）

## なぜやるか

いまビームは艦を素通りする。射線を遮るのは恒星と基地だけで、
味方が敵に張り付いていても後ろから安全に撃ち抜ける。

[Product Guide](../product.md) は「味方は守る対象であり頼る対象でもある」と
定めているが、**攻撃の場面ではその関係が成立していない。**
味方の位置を気にする理由がないためで、この Track はそこを埋める。

## 決めたこと

| | |
|---|---|
| ビームは味方で止まる | 標的の敵は無傷。失敗がはっきり伝わる |
| 基地も誤射の対象 | 基地の手前での交戦がリスクになる。プレイヤーが基地越しに撃てる非対称も解消 |
| 事前の予告は入れない | まず挙動だけ。分かりやすさの手当ては挙動を見てから |

## 影響の範囲

**ゲームバランスが変わる。** 挙動を変えない前提の突き合わせ
（`regression`）は「一致しない」のが正しく、
差が出た箇所が誤射と回避だけであることを読む形になる。

判定の入口は `isLOSBlocked()`（`index.html`）に集約されており、
呼び出し元は NPC の `evaluateTactics()` とプレイヤーの攻撃の2箇所だけ。
ただし**ダメージを与える経路は別**（プレイヤーは `EnemyShip.onInteract()`、
NPC は `SpaceShip.attack()`）なので、両方に効かせる必要がある。
