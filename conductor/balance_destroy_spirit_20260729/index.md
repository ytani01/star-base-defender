# Track: 撃破したその場で敵の士気を上げる

敵艦を撃破すると、生存している敵の士気が上がるようにする。
撤退させたときに士気が下がるのと、正確に裏返しの関係にする。

- [Spec](./spec.md) — 何を実現するか、何をやらないか
- [Plan](./plan.md) — フェーズ分けしたタスクリスト（進捗の唯一の正）

## なぜやるか

[Product Guide](../product.md)「敵の心理」は
**「撃破すれば士気が上がり、撤退させれば士気が下がります」**と定めているが、
実装で動いているのは**撤退側だけ**だった。

いま士気が上がるのは25ターンごとの増援のときだけで、これはプレイヤーの
行動と無関係な時間経過にすぎない。**「プレイヤーの行動に反応する」という
部分が片側しか成立していない。**

結果として「破壊は戦局を悪化させる」という中核の言い分のうち、
効いているのは増援と減点だけになっている。

## 決めたこと

| | |
|---|---|
| 上げ幅は `SPIRIT.STEP`（0.05） | 撤退時の下げ幅と同じ。対称にし、新しい定数を増やさない |
| 対象は生存中の全ての敵 | 撤退時（残った敵全体が下がる）と完全に対称。距離で重み付けしない |
| 増援は上昇を受けない | いま到着したところで、仲間が落ちる場を見ていない |
| ログで知らせる（副長） | 士気は画面に出ない。ログがないと「破壊は戦局を悪化させる」を学べない |

## 影響の範囲

**ゲームバランスが変わる。** 士気は2つのことに効く。

- **逃走の閾値** `1 − spirit`。0.5 なら 50% で逃げ出すが、上限 0.7 では
  30% まで粘る。**4回撃破すれば上限に達する。**
- **交戦距離** `maxRange × (1 − spirit)`。士気が高いほど近づいてから撃つ。
  ビームは距離で減衰するので、**近いほど威力が上がる。**

撃破の罰が増援・減点・士気の3つ重なることになる。強すぎないかは
実際に遊んで見るほかない（Plan の Phase 3）。

撃破の入口は前 Track [fix_destroy_spawn_20260729](../archive/fix_destroy_spawn_20260729/index.md)
で `EnemyShip.onDestroyed()` に集約済みで、経路ごとの取りこぼしは起きない。
**逆に、ここに書いたことは4経路すべてに効く。**
